## 本次版本内容

- 把 Aspen COM 的单案处理扩展为可在 GUI 中编排的严格串行 Aspen Suite；每案使用隔离副本和独立输出目录，记录源文件哈希、运行状态、原始历史、物性补充、设备/管线推导和正式工艺基础门禁。
- 管线、泵、换热器、塔器及其余设备族在输入不全时仍生成完整的程序候选，同时逐字段标注登记默认值或内置公式、J 类证据和禁止直接采购/施工/报审的警告。
- 对大换热器和奇异泵工况给出受约束的分台、并联、串联及单台目标规格，并把总量守恒、算法适用边界和厂家复核要求写入输出。
- 将设备基本信息、自然语言分支说明、详细计算链、材料/零部件选择、AI 建议及证据缺口分层展示；支持用户修改参数、单设备重算和恢复默认。
- 更新现代化 Windows GUI：响应式左右工作区、可折叠导航、结果摘要、详情对话框、队列状态和更明确的操作反馈。
- 受控 AI 仍为非权威建议层：程序只提供当前设备族的候选、依据、知识片段和允许修改范围；确定性计算结果、证据门和正式使用状态不能被模型静默覆盖。
- 正式构建支持从冻结知识归档恢复大型运行资产，再用当前仓库规则覆盖更新，避免公开源码仓库未携带大型 SQLite 时生成空壳软件。

## 证据边界

该版本已经能形成完整、具体且可追溯的程序选型候选，但仍属于预设计和算法初筛。下列内容没有被伪装成已经完成：

- 泵厂家正式型号及完整 Q-H、效率、功率、BEP 和 NPSHr 曲线；
- 换热器 EDR/HTRI 等同工况热工水力核算和厂家机械设计；
- 塔内件厂家液泛、持液量、压降和传质效率保证；
- 完整管网压降、管道应力、腐蚀寿命和压力—温度额定；
- DOCX/PDF 正式报告、CAD/P&ID 自动出图及无人批准的闭环 Agent；
- 远程 LLM 服务的生产闭环验收。

程序会把这些内容保留为 `provisional`、`TYPE_SCREENING`、开放证据缺口或固定警告。AI 只能组织答案和提出登记范围内的建议，不能把程序候选晋升为正式采购型号。
